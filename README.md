# Лабораторная работа №1: Вычисление бесконечных рядов (Java)

## Описание задачи
Программа вычисляет значение экспоненциальной функции $e^x$ через разложение в ряд Тейлора с заданной точностью $\epsilon$.

### Основные требования:
1. Аргумент `x` и точность `k` (количество знаков) вводятся пользователем.
2. Использование класса `BigDecimal` для обеспечения высокой точности вычислений.
3. Итерационный процесс продолжается до тех пор, пока очередной член ряда не станет меньше $\epsilon = 10^{-k}$.
4. Сравнение результата с эталонным значением `Math.exp(x)`.

---

## Структура проекта (ООП)
Проект разделен на логические модули в пакете `com.company.exponential`:

* **Main**: Обработка пользовательского ввода через `Scanner` и запуск вычислений.
* **ExponentialCalculator**: Ядро программы. Содержит алгоритм вычисления суммы ряда и управление количеством итераций.
* **ResultFormatter**: Отвечает за представление чисел в экспоненциальной форме (`0.000E0`) и расчет разницы между значениями.

---

## Инструкция по использованию

### Запуск
1. Откройте проект в **IntelliJ IDEA**.
2. Запустите класс `Main`.
3. Введите `x` (аргумент) и `k` (желаемая точность).
