# Лабораторная работа №2: Обработка двумерных массивов и файловый I/O

## 📖 Описание задачи
Программа предназначена для чтения матрицы из текстового файла и поиска столбца, удовлетворяющего заданным критериям фильтрации и экстремальности.

### Условие задачи:
Среди столбцов заданной матрицы, содержащих только такие элементы, которые **по модулю не больше $n$** ($|a_{ij}| \le n$), найти столбец с **минимальным произведением** элементов.

### Основные требования:
1. **Файловый ввод**: Чтение данных из внешнего `.txt` файла (первая строка — размерность или сразу элементы).
2. **Параметризация**: Пользователь вводит порог $n$ для фильтрации элементов.
3. **Обработка ошибок**: Использование блоков `try-catch-finally` для обработки отсутствия файла (`IOException`) и ошибок формата данных (`NumberFormatException`).
4. **Результат**: Вывод исходной матрицы, расчетных данных по подходящим столбцам и подробной информации о найденном столбце.

---

## 🛠 Структура проекта (ООП)
Проект спроектирован с разделением ответственности между классами в пакете `com.matrix`:

* **Main**: Точка входа, запускает процесс анализа.
* **MatrixAnalyzer**: Контроллер, координирующий чтение файла и запуск вычислений.
* **MatrixOperations**: Вычислительный модуль, содержащий логику проверки условий и расчет произведения элементов.
* **MatrixFileReader**: Модуль ввода-вывода, отвечающий за парсинг текстового файла и консольный интерфейс.

---

Файл должен содержать целые числа, разделенные пробелами или табуляцией. Каждая новая строка файла соответствует новой строке матрицы.

**Пример (matrix.txt):**

10  5   2
 4  -3  8
